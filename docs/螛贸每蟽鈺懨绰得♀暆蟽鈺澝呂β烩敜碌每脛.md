# 题库 JSON 格式

顶层字段：`schemaVersion`、`updatedAt`、`difficulties`、`quizzes`、`questions`。

题库对象：
```json
{
  "id": "quiz-starter",
  "title": "动漫入门热身",
  "description": "题库简介",
  "difficulty": "入门",
  "questionIds": ["q1", "q2"],
  "published": true
}
```

题目对象：
```json
{
  "id": "q1",
  "type": "single",
  "question": "题目内容",
  "options": ["选项 A", "选项 B"],
  "answer": 0,
  "explanation": "答案解析",
  "image": "assets/images/example.webp",
  "audio": "assets/audio/example.mp3"
}
```

填空题 `answer` 可写字符串或字符串数组；其他选项题的 `answer` 是从 0 开始的选项索引。不要在题目里添加 `anime` 或 `work` 字段。
